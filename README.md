# DSH 统一桥接 (Unified Tavern) —— 手机酒馆扩展

本扩展用于在 **SillyTavern / TauriTavern** 中直连电脑端的 **DSH (DeepSeek Harness)**，实现消息互通、会话同步与智能生图控制。

---

## 安装方法

在手机酒馆的 **扩展 (Extensions) -> 安装扩展** 中，填入本 GitHub 仓库地址：

```text
https://github.com/你的用户名/你的仓库名.git
```

安装完成后刷新酒馆页面即可。

---

## 配置说明

安装后进入酒馆的「扩展设置」面板：
1. 找到 **DSH 统一桥接 (Unified Tavern)** 折叠卡片。
2. 勾选 **启用 DSH 桥接**。
3. 在 **电脑桥接地址** 中填入你电脑局域网的 IP 和端口（例如 `http://10.105.77.189:43121`）。
4. 点击 **测试电脑连接**，显示“连接成功”即代表手机与电脑 DSH 通信正常！
